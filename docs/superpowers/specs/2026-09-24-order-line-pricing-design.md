# 正式订单尺码单价设计

## 目标

在正式订单的每条尺码明细中保存商品单价，由管理员录入和修改，系统自动计算尺码金额与整张订单金额。价格属于内部财务信息，不向员工端或客户版导出公开。

## 已确认规则

- 单价属于订单中的具体尺码明细，不属于 SPU 或 SKU 公共资料。
- 币种固定为人民币，单价最多保留两位小数，不能为负数。
- 历史订单的单价保持空值并显示“未填写”，不能用 `0.00` 代替未知价格。
- 新建正式订单时单价可以填写，也可以留空，由财务使用管理员账号后续补录。
- 管理员可以在正式订单详情页逐尺码修改单价。
- 尺码金额等于该尺码的下单数量乘以单价。
- 所有有效尺码均已填写单价时，显示整张订单总金额。
- 只要存在未填写单价的有效尺码，显示“总金额待补全”，同时显示已填写部分小计和未填写尺码数量，避免把部分金额误认为完整订单金额。
- 价格和金额只显示在管理员页面及内部版 Excel；员工端和客户版 Excel 均不显示，也不从员工使用的接口返回。
- 每次单价修改记录订单号、尺码、原单价、新单价、操作者和时间。
- 离职员工使用现有账号“停用”功能处理，不删除账号及历史业务记录。本功能不新增财务角色，财务使用管理员账号。

## 方案选择

采用“单价保存在订单尺码明细”方案。每次订单成交价随订单行保存，历史价格不会因 SKU 或 SPU 的未来价格变化而改变。

未采用以下方案：

- SKU 统一价格：无法准确表达同一 SKU 在不同订单中的成交价。
- 独立价格历史表：当前只需要订单行当前价格及操作审计，单独建表会增加不必要的查询和维护成本。

## 数据结构与迁移

在 `order_lines` 增加可空的 `unit_price` 字段，数据库类型使用定点小数，例如 `NUMERIC(12, 2)`。空值表示尚未填写；`0.00` 表示明确的零单价，两者语义不同。

迁移脚本应满足：

- 使用 `ADD COLUMN IF NOT EXISTS`，便于核查后安全重跑。
- 不回填历史数据。
- 增加非负约束，接口层同时校验两位小数和允许范围。
- 生产迁移前备份 PostgreSQL，迁移后检查字段、约束、应用账号权限和现有行仍为空值。

金额只在读取时使用定点小数计算，不另外保存派生金额，避免数量或单价修改后出现不一致。

## 管理员页面

### 新增正式订单

尺码明细每行增加“商品单价”输入框：

- 接受空值或最多两位小数的非负金额。
- 新增尺码时单价默认为空。
- 提交后由服务端再次验证，不能只依赖浏览器校验。

### 正式订单详情

尺码表增加“商品单价”和“尺码金额”两列：

- 未填写显示“未填写”。
- 已填写统一显示两位小数。
- 尺码金额为下单数量乘以单价。
- 每行提供管理员可用的编辑入口，保存成功后刷新订单金额。

订单信息区域显示金额汇总：

- 全部已填：显示“订单总金额 ¥X.XX”。
- 部分未填：显示“总金额待补全”，并显示“已填写小计 ¥X.XX；N 个尺码未填写”。

订单余额页本轮不增加价格列，避免改变用户刚确认的精简列表；系统订单号仍进入完整订单详情。

## 接口与权限

- 创建正式订单的管理员接口接受每条尺码的可空 `unit_price`。
- 管理员正式订单详情接口返回单价、尺码金额和订单金额汇总。
- 增加管理员专用的订单行单价更新接口。
- 更新接口校验订单行存在、属于目标正式订单、价格格式合法，并在同一业务操作中写入操作日志。
- 管理员接口继续使用现有管理员鉴权。
- 手机端及员工业务接口的响应结构不增加价格字段。
- 日志内容不包含密码或其他敏感凭据。

## 内部导出

内部版工作簿中与订单余额相关的工作表增加“商品单价”和“金额”列：

- 有价格时写入数值单元格，并使用两位小数人民币格式。
- 未填写价格时保持空白，不能写零。
- 金额为下单数量乘以单价。
- 同一内部工作簿中的订单明细口径保持一致。

客户版工作簿的列、内容和格式保持现状，不出现单价、金额或任何价格汇总。

## 审计与错误处理

价格更新日志至少包含：系统订单号、订单行 ID、尺码、修改前单价、修改后单价、操作者和服务器时间。首次从空值补录和清空错误价格也需要记录。

遇到非法金额、订单行不匹配或记录不存在时，服务端拒绝修改并返回明确错误；页面保留原值并显示错误消息。快速切换订单或尺码时沿用现有请求版本保护，避免旧响应覆盖当前页面。

## 测试与验收

自动测试覆盖：

- 数据库旧结构升级后新增可空字段且历史值为空。
- 创建订单时可留空或填写单价，拒绝负数和超过两位小数的输入。
- 订单详情正确返回尺码金额、完整总金额和待补全状态。
- 管理员修改、清空单价均写操作日志。
- 非管理员不能调用价格修改接口。
- 内部版包含单价与金额，未填价格保持空白。
- 客户版不包含任何价格字段。
- 员工相关页面与接口不出现价格。

上线验收覆盖：

- 先备份生产数据库和应用代码，再执行迁移与部署。
- 使用管理员测试订单的新建、补录、修改、清空和金额汇总。
- 导出内部版检查数值与格式，导出客户版确认无价格。
- 使用员工账号检查发货选择、我的上报等页面没有价格。
- 核对服务健康、操作日志、服务器 Git 状态和回退点，并更新共享接手记录。

## 不在本次范围

- 多币种、税率、折扣、成本价、已收款和欠款管理。
- 按 SKU 自动带默认价。
- 独立财务角色或新的权限体系。
- 删除用户及其历史记录；离职账号使用停用功能。
