# 内部版导出新增快递记录页设计

## 目标

在两种内部版 Excel 导出中新增独立工作表“快递记录”：

- 全部公司内部总表；
- 单个公司内部版。

客户版导出不改动。

## 工作表结构

“快递记录”工作表一张快递单一行，只包含三列：

1. 快递单号；
2. 重量(kg)；
3. 发货日期。

时间字段使用快递记录的实际发货日期 `WaybillRecord.ship_date`，不使用记录录入时间 `created_at`。

## 数据来源与筛选

数据直接读取 `waybill_records` 主表，不从发货流水反推，因此：

- 一张快递单即使关联多份发货明细，也只导出一行；
- 尚未挂靠发货明细的真实快递单仍会导出；
- 全部公司内部总表包含所有快递记录；
- 单个公司内部版只包含 `company_name` 与所选公司一致的快递记录。

## 排序和空值

- 先按发货日期从早到晚排序；
- 同一日期按快递单号排序；
- `weight_kg` 未填写或为 0 时，Excel 单元格留空，避免把 0kg 误解为真实重量；
- 无快递记录时仍保留工作表和表头。

## 样式

复用现有导出工作表样式：表头加粗和底色、居中、自动列宽、冻结首行。

## 实现边界

- 在 `app/services/exports.py` 中增加单一职责的快递记录工作表生成函数；
- `export_total_workbook` 与 `export_company_workbook` 调用该函数；
- 客户版、发货流水、订单余额计算和数据库结构均不变；
- 不需要数据库迁移。

## 验证

自动测试覆盖：

- 内部总表包含“快递记录”页及正确三列表头；
- 单公司内部版只包含该公司的快递单；
- 一张关联多份发货的快递单只出现一次；
- 未挂靠快递单仍出现；
- 0 重量导出为空白；
- 日期和单号排序正确；
- 客户版工作表列表保持不变。
