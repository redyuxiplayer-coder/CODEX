# ZY服装发货管理系统

这是第一版仓库局域网发货系统。

## 启动

双击 `启动ZY发货系统.bat`。

电脑端打开：

`http://127.0.0.1:8000/admin`

手机端连接同一个 WiFi 后打开：

`http://主电脑IP:8000/mobile/login`

## 管理员账号

系统不会在公开文档里写真实账号密码。

首次部署空数据库时，请在服务器环境变量里设置：

- `ZY_INITIAL_ADMIN_USERNAME`
- `ZY_INITIAL_ADMIN_PASSWORD`

已有数据库不会覆盖现有账号。仓库账号请由老板登录后到“账号管理”里新增。

仓库账号：

仓库账号不默认创建。

## 第一版能做什么

- 老板电脑端查询订单下单、已发、未发、超发。
- 老板电脑端新增订单。
- 老板电脑端导入现有 Excel 总表。
- 仓库员工手机端点选公司、产品、款式、尺码数量上报发货。
- 手机端上传照片。
- 正常发货自动通过。
- 超发、无订单、重复嫌疑进入待审核。
- 老板电脑端审核通过或驳回。
- 导出总表、未发货表、公司表、日期发货表。

## 数据备份

重要数据在 `data` 文件夹里，包括数据库、上传照片和导出的表格。

备份时复制整个 `data` 文件夹即可。
